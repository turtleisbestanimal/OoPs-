# OoPs 기획 기록

**편집 전 원본 영상을 분석해, 편집자가 검토할 발언과 근거를 제공하는 영상 콘텐츠 리스크 관리 서비스.**

최종 갱신: 2026-10-29. 서비스 개편과 후속 확인 사항의 사용자 확정 내용을 반영했다. 기획 문서 갱신이며 백엔드 구현·배포 완료를 뜻하지 않는다.

## 현재 기준

- 영상 업로드 / 테스트용 스크립트 / 전사 재사용 → Groq whisper-large-v3 전사 → 맥락 확인·사실대조 → 결과 검증·제공.
- 맥락 확인은 Neo4j 공통 기준→독립 중단·제외 점검→추가 기준이다. 상세 중단 원칙은 후속 작성한다.
- 문맥은 30초 대상+앞뒤 각 30초, 불분명하면 각 60초로 한 번 확대한다. 서비스 내 직접 영상 편집과 YouTube 링크 입력은 제외한다.
- 사실대조는 별도 GPT 주장 추출과 Perplexity 메인·Serper 보조 검색이다. 두 흐름은 독립적이다.
- 발언·자막 비교를 제거한다. 사용자에게는 발언·실제 시각·탐지/판단 기준·근거·실제 사용한 검색 출처를 제공한다.
- 과거 사례·관계지도·정보 부족 항목은 사용자 결과에서 제외한다. 기획과 실제 구현·배포는 구분한다.
