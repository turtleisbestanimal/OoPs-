## 다섯 가지 핵심 문서

- **[전체 기획서](전체_기획서.md)** — 제품·고객·분석·사업모델·실행계획·팀을 상세히 정리합니다. 확정 사항, 계획, 구현 확인, 미결 내용을 구분합니다.
- **[검토 사항: 중복·차이](검토_사항.md)** — 자료 간 중복·차이, 확인 질문, 사용자 답변을 관리합니다.
- **[AI 작업 지침 및 시작 문구](AI_작업_지침_및_시작_문구.md)** — 새 AI는 이 문서 하나부터 읽습니다. 업데이트 지침, 시작 문구, 현재 상태, 결정 이력, 다음 작업을 함께 담았습니다.

- **[다른 AI 작업 기록](다른_AI_작업_기록.md)** — 다른 AI에서 작업한 자료로 제공받은 16개 파일의 전체 원문을 한 문서에서 읽습니다.
- **[기획의 코드 미반영 사항](기획_코드_미반영_사항.md)** — 최신 확인 코드와 기획을 대조해 미구현·부분 구현 항목과 근거를 정리한 다섯 번째 문서입니다. 일반 후속 과제는 검토 사항에서 별도로 관리합니다.

앞으로 “확정한 내용을 전체 기획서에 반영해줘”라고 요청하면 기획서·검토 사항·통합 AI 문서를 함께 갱신합니다. 네 번째 문서는 과거 원문 모음이므로 새 결론에 맞춰 원문을 고쳐 쓰지 않습니다.

## 이번 반영 범위

2026-09-19 재첨부한 `OoPs_Master_Context_v1`의 **16개 파일을 모두 읽었습니다.** 기존 대화·백엔드 확인 내용과 함께 정리했고, 사용자가 답한 향후 기능과 목표 정책을 반영했습니다.

이전에 별도로 언급한 `OoPs_신청서_전체본문.md`는 이번 폴더에 없으므로 아직 통합하지 않았습니다. 폴더의 16개 원문과 별도 신청서 파일의 상태를 구분합니다.
