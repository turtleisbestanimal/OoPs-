## 다섯 가지 핵심 문서

- **[전체 기획서](전체_기획서.md)** — 제품·고객·분석·사업모델·실행계획·팀을 상세히 정리합니다. 확정 사항, 계획, 구현 확인, 미결 내용을 구분합니다.
- **[검토 사항](검토_사항.md)** — 아직 판단하거나 설계·확인해야 할 항목만 기획·디자인·기술로 나눕니다.
- **[AI 작업 지침 및 시작 문구](AI_작업_지침_및_시작_문구.md)** — 새 AI는 이 문서 하나부터 읽습니다. 업데이트 지침, 시작 문구, 현재 상태, 결정 이력, 다음 작업을 함께 담았습니다.

- **[다른 AI 작업 기록](다른_AI_작업_기록.md)** — 다른 AI에서 작업한 자료로 제공받은 16개 파일의 전체 원문을 한 문서에서 읽습니다.
- **[검토 완료 사항](검토완료사항.md)** — 확정된 답변·문안 정리·코드 대조 결과를 기존 ID와 근거를 보존해 기록합니다.

앞으로 “확정한 내용을 전체 기획서에 반영해줘”라고 요청하면 기획서·검토 사항 또는 검토 완료 사항·통합 AI 문서를 함께 갱신합니다. 네 번째 문서는 과거 원문 모음이므로 새 결론에 맞춰 원문을 고쳐 쓰지 않습니다.

## 최신 반영 — 2026-10-10

선택 구간을 삭제하고 나머지를 연결하는 수정 기획, PostHog 이용 분석 방향, 자막 입력 .srt 변경을 반영했습니다. 편집도구 비교·선정은 R-29, 삭제 구현 검증은 GAP-13, PostHog 계측·수집 검증은 GAP-14에서 관리합니다. 기획 반영이며 기능 구현·도구 선정·운영 검증 완료가 아닙니다.

## 이번 반영 범위

2026-09-19 재첨부한 `OoPs_Master_Context_v1`의 **16개 파일을 모두 읽었습니다.** 2026-09-29에는 실제 제출한 **모두의 창업 지원서 본문**을 최신 기획 기준 자료로 추가 반영했습니다. 이후 사용자가 별도로 확정한 첫해 매출 계획 2,049,700원은 유지하고, 팀 소개는 익명 번호 대신 역할 중심으로 정리했습니다.
