# 현재 작업 맥락 — 원문 대조 전 임시 요약

기준일: 2026-09-19. 첨부 원문 17개를 아직 읽지 못했으므로 최종 통합본이 아니다. 아래는 현재 대화에서 사용자가 제공한 내용과 저장소 확인 사실을 출처별로 구분한 요약이다. 원문의 문장을 대체하거나 삭제하기 위한 문서가 아니다.

기획 기준 저장소: https://github.com/turtleisbestanimal/OoPs- . 아래 개발 문서와 코드 경로는 모두 별도 백엔드 저장소 https://github.com/LikeLionHGU/oops_backend 기준이다.

## 사용자 설명: 제품과 고객

- 서비스명: OoPs?! (기존 자료에는 oops, OOPS 표기도 존재).
- 유튜브 대화형 콘텐츠의 공개 전 검수를 돕는다. 인터뷰·웹 예능·팟캐스트 등 긴 영상을 반복 제작하는 크리에이터와 제작팀이 주요 대상이며, 연예인 출연 콘텐츠도 중요 대상으로 설명했다.
- AI가 옳고 그름이나 삭제 여부를 단정하는 대신 다시 확인할 지점, 시각, 확인 이유, 관련 자료를 제시하고 제작자가 판단한다.
- 제시한 이용 흐름: 영상 업로드 → 분석 → 시간순 검토 후보 확인 → 이유·맥락·근거 확인 → 수정·유지·보류 기록.
- 수동 검수 및 범용 AI와의 차별점은 검토할 장면 발견부터 자료 확인과 결정 기록까지 이어지는 이용 흐름이다.
- 현업 PD·크리에이터 포함 4명을 인터뷰했다고 설명했다. 반복 검토 중 무뎌짐, 낯선 표현·사회적 배경을 모르는 경우에 주목했다.
- 피식대학 영상에서 발언 후보를 찾고, 크리에이터 영상에서 발언 1997년/자막 1998년의 차이를 찾았다고 설명했다. 테스트 당시 버전과 설정은 확인되지 않았다.
- 인스타그램 광고 이미지의 반응은 초기 관심 신호로 설명하려 했다. 별도 광고 화면에는 조회수 4,705, 도달 4,112, 웹사이트 방문 36이 표시됐다. 다른 게시물 화면의 통계와 합산하거나 유료 고객 수로 해석하지 않는다.
- 멋쟁이사자처럼 중앙해커톤 예선 통과 및 최종 15팀 선정은 사용자 제공 성과다. 이를 초기 외부 평가로 설명하며, 유료 수요·사업성 검증 완료와 구분한다.

## 사용자 설명: 수익모델과 목표 (계획)

- 기본 월 구독료 19,900원 / 월 20시간 / 초과 시간당 1,000원.
- 사용자 제공 분석 로그 설명: 60분 영상의 모델 사용 비용 약 550원, 그중 Whisper-1 약 504원. 서버·저장·결제·지원 비용은 별도다.
- 20시간 모델 비용 약 11,000원, 구독료와 차액 8,900원. 초과 1시간 차액 약 450원. 차액은 순이익이 아니다.
- 소형 제작팀 월 49,000~99,000원, 다채널 제작사 월 150,000~300,000원 또는 맞춤 견적은 계획이다. 제공 시간·인원은 미확정.
- 초기 유료 고객 5명, 6개월차 10명이 목표다. 이미 확보한 고객으로 쓰지 않는다.
- 매출 예시: 5명 월 99,500원 / 10명 월 199,000원 / 고객 1명 연 환산 238,800원 / 월평균 5명 가정 연 1,194,000원. 6개월차 10명 목표와 자동으로 일치하는 실적 예측은 아니다.
- 구매 가치는 반복 검수·자료 확인 부담 경감이다. 논란 방지나 손실 회피를 보장하지 않는다.

## 저장소 확인: 기술 및 적용 범위

기준 커밋 `e6b7003`; 운영 환경은 별도 미확인.

- Java 17 / Spring Boot 4.0.5 / Spring Data JPA / REST API / WebSocket.
- Python / FastAPI, OpenAI Whisper-1, OpenAI GPT-4o mini API, PaddleOCR·OpenCV, FFmpeg·yt-dlp.
- 기본 DB H2 파일 모드; MySQL 연결 설정은 존재. 팀원의 MySQL 경험과 현재 서비스 DB를 혼동하지 않는다.
- Google News RSS, 설정값이 있을 때 이용 가능한 Naver News API 연동.
- Vercel 프론트 주소가 명시됨. React/Next.js 및 디자인·코딩 보조도구는 이 백엔드만으로 확인하지 못함.
- 발언 사실 확인은 활성, 화면 글자 사실 확인과 발언↔자막 직접 비교는 기본 비활성. 화면 글자의 일반 내용 검토와 사실 확인은 구분한다.
- 원본 영상: 완료 후 24시간이 지난 대상을 매시 정각 정리. 대본·리포트·후보·근거·이력·캡처는 별도이며 전체 자료 자동 정리는 기본 비활성.
- 인증은 기존 개발 문서에 미구현으로 기록돼 있다. 결제·팀별 권한 등 사업 계획을 구현 완료로 바꾸지 않는다.
