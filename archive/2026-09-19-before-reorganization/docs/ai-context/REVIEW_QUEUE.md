## 해석·기획·구현 차이

**R-01 — 발언과 자막의 차이 탐지 / 사용자 확인 필요**

- 현재 대화: 발언 1997년과 자막 1998년의 차이를 찾은 사례, 발언·자막을 함께 확인하는 기능을 설명했다.
- 백엔드 `e6b7003`의 `application.yml`: `caption-mismatch`는 활성 분석기에서 제외돼 있다. 편집 자막과 환경 글자를 구별하기 어려워 껐다는 설명이 있다.
- 동시에 `fact-check-screen-text: false`이며, 화면 글자 내용 검토 자체는 활성이다. 두 기능을 혼동하지 않는다.
- 질문: 사례는 과거 테스트 설정의 결과인가? 신청서에서는 해당 기능을 현재 기본 제공으로 쓸지, 테스트 확인/개선 예정으로 쓸지?
- 현재 조치: 사례나 기획 문장을 삭제하지 않고 ‘기본 설정과 차이, 사례의 버전 미확인’으로 기록.

**R-02 — 원본 ‘24시간 이내 삭제’ / 사용자 확인 필요**

- 실행 계획의 표현: 분석 완료 후 24시간 이내 원본 삭제 정책을 확인한다.
- 코드: 보관 기준 24시간, `StorageCleanupScheduler`가 매시 정각에 기준을 지난 원본을 정리한다. 정상 실행 시에도 완료 시점에 따라 약 24~25시간이 걸릴 수 있고, 서버 중단 시 더 늦을 수 있다.
- 추출 대본·캡처·리포트·근거·검수 이력은 남으며, 전체 자동 정리 `retention-days`의 기본값은 0이다.
- 질문: ‘24시간 이내’를 앞으로 충족할 목표로 유지할지, 현재 방식에 맞는 설명으로 바꿀지? 파생 자료의 보관·삭제 정책은 무엇인지?
- 현재 조치: 정책이나 코드를 변경하지 않았다.

**R-03 — 팀원 2의 AI 노인 케어 참여 역할 / 사용자 확인 필요**

- 초기 경력 목록: 기획 참여.
- 후기 소개 문안: 개발 참여.
- 질문: 실제 역할은 기획, 개발, 또는 둘 다인가?
- 현재 조치: 양쪽 표현을 보존하고 어느 쪽도 확정하지 않았다.

**R-04 — 초기 검증의 범위 / 표현 확인 필요**

- 대화의 근거: 인터뷰 4명, 일부 영상 분석 사례, 중앙해커톤 최종 15팀 선정, 광고 반응.
- 같은 대화의 계획: 사용 테스트·반복 사용·유료 전환은 앞으로 확인한다.
- 질문: ‘초기 검증’은 문제 탐색·기능 테스트·외부 평가까지를 뜻하는지? 이미 결제/반복 이용한 고객이 있는지?
- 현재 조치: 수요·사업성 검증 완료 또는 유료 고객 확보로 확대 해석하지 않는다.

**R-05 — 연 매출 예시와 6개월 고객 목표 / 가정 확인 필요**

- 연 1,194,000원은 월평균 고객 5명 × 19,900원 × 12개월이다.
- 4개월차 첫 유료 고객 5명, 6개월차 10명이라는 실행 목표만으로는 연간 월평균 고객 수가 결정되지 않는다.
- 질문: 연 매출 수치는 계산 예시로 유지할지, 월별 고객 가정에 맞춘 계획으로 새로 작성할지?
- 현재 조치: 기존 수치는 예시로만 유지. 새 매출 수치나 유지율을 만들지 않는다.

**R-06 — 기능·기술의 계획과 구현 / 근거 구분**

- 현재 DB 기본 설정은 H2 파일 모드, MySQL은 연결 설정이 있다. 팀원의 MySQL 경험은 서비스의 운영 DB 증거가 아니다.
- Vercel은 프론트 배포 근거이며 백엔드 배포 플랫폼이라고 쓰지 않는다.
- GPT-4o mini API 사용을 ChatGPT 웹 서비스 사용과 동일시하지 않는다.
- 권한 관리·결제·팀별 상품 등은 기획 목표와 현재 구현을 구분한다. 운영 설정이 필요하면 별도 확인한다.

**R-07 — 과거 개발 문서 안의 완료 전/후 서술 혼재 / 참고 시 주의**

- `기획서-구현-격차분석.md`는 ‘근거 저장 해결됨’ 아래에 과거의 ‘현재: 저장하지 않는다’, ‘해야 할 일’을 역사 기록으로 남긴다. 배포 완료 자료와 ‘그다음 배포’ 문구도 공존한다.
- `프로젝트-현황-정리.md` 머리말 날짜는 2026-08-12이지만 이후 구현 내용이 포함돼 있다.
- 현재 조치: 제목 날짜나 ‘현재’라는 단어만으로 최신 상태를 판단하지 않는다. 코드 기준 커밋과 완료 표시를 함께 확인한다. 기존 개발 문서는 수정하지 않았다.
