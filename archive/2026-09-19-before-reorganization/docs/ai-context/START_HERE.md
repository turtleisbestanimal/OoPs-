# 다른 AI에서 이어서 작업하는 방법

아래 문구를 새 채팅에 전달한다. 저장소를 직접 열 수 없는 AI에는 같은 파일들을 첨부한다.

> OoPs?! 기획 작업을 이어서 진행해주세요. 기획 기준 저장소는 https://github.com/turtleisbestanimal/OoPs- 입니다. 먼저 루트 AGENTS.md와 docs/ai-context/README.md, HANDOFF.md, CURRENT_CONTEXT.md, REVIEW_QUEUE.md, SOURCE_INDEX.md, DECISIONS.md, 최근 SESSION_LOG.md를 읽어주세요. 원문·사용자 진술·구현 확인·계획·미결 질문을 구분하고, 원문이나 사업 내용을 임의로 추가·삭제하지 마세요. 중복과 충돌은 출처를 함께 남겨 제가 검토하게 해주세요. 애매한 부분은 질문하고, 답변 전에는 확정하지 마세요. 매 작업 대화를 마칠 때 맥락·결정·검토 목록·작업 기록·다음 단계를 갱신하고 이 기획 저장소에 반영해주세요. GitHub에 올리지 못한 경우에는 로컬 변경과 실패 이유를 분명히 알려주세요. HANDOFF.md의 미완료 작업부터 이어가주세요.

현재 진행 상태가 바뀔 수 있으므로 이 시작 문구보다 `HANDOFF.md`의 최신 상태와 이후 사용자 지시를 확인한다. 인수인계 문서는 대화 요약이며 원본 채팅 전문은 아니다.
